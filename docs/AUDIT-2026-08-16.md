## Проверено — здорово ✅

- **Секреты:** в git только `.env.example`; `.env*` в `.gitignore`; закоммиченных ключей/паролей нет.
- **N+1:** `select_related`/`prefetch_related` грамотно расставлены в pets/chat/ai/notifications/billing views.
- **Безопасность HTTP:** nginx — TLS 1.2/1.3, HSTS, nosniff, DENY frame, CSP, Referrer-Policy; защищённые медиа (`vet_docs`, чат-аттачи, доки событий) идут через Django-auth, публичные — напрямую.
- **Инфраструктура:** redis не публикует порты наружу; backend/frontend `expose`-only; CI прогоняет check + migrations + tests + tsc + build.
- **i18n:** `en.json`/`ru.json` консистентны, Header/Footer/Layout на `next-intl`.
- **Auth:** JWT с ротацией refresh + blacklist, троттлинг (auth 10/h, ai 20/h), DRF default `IsAuthenticated`.
- **Focus-состояния:** глобальный `*:focus-visible` + `focus-ring` в utilities-слое; двойного кольца нет (utilities бьёт base).
