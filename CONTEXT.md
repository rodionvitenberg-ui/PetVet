# PetVet — контекст ядра (управление здоровьем питомцев)

Единый контекст платформы: владелец ведёт здоровье питомца (карточка, события, календарь, AI-консультации), ветеринар работает с «теневыми» картами до подтверждения владельца, клиника обслуживает пациентов и выставляет счета. Один словарь на весь репозиторий — backend (Django) и frontend (Next.js) говорят на нём на равных.

## Ядро: питомец и доступ

**Pet (Карточка питомца)**:
Единица домена, вокруг которой строится всё: здоровье, события, доступ, счета. Владеет либо реальный пользователь, либо (до регистрации) врач создавший теневую карту.
_Avoid_: Patient (это роль питомца в контексте клиники), животное

**Pet Owner (Владелец питомца)**:
Пользователь, которому принадлежит питомец (FK `Pet.owner`). Единственный, кто по умолчанию имеет полный доступ.
_Avoid_: хозяин, Client (см. Client)

**Shadow Pet (Теневая карта)**:
Карта питомца без владельца (`owner is null`), созданная ветеринаром до регистрации владельца; идентификация временная — `temp_owner_name`/`temp_owner_phone`. При регистрации владельца карта «привязывается» к нему и перестаёт быть теневой.
_Avoid_: предварительная карта, guest-питомец

**Shadow Creator**:
Ветеринар, создавший теневую карту (`Pet.created_by`). Сохраняет доступ к теневой карте, пока у неё нет владельца.
_Avoid_: автор, врач-создатель

**Client (Клиент)**:
Единая сущность человека в системе: реальный пользователь (`is_temporary=false`) или временный субъект из теневой карты / гостевых полей события / имени в счёте (`is_temporary=true`). Резолвится единым `resolve_client()` из любой модели-источника; у временного клиента `id` отсутствует.
_Avoid_: guest, temp_owner, покупатель (это роли-источники, не отдельные сущности)

**PetAccess (Grant, Доступ к питомцу)**:
Разрешение для пользователя видеть и/или редактировать питомца, полученное через QR-ссылку. Уровень `read` (по умолчанию) или `write`; активность — флаг `is_active`. QR-токен подписан `TimestampSigner` (TTL 1 час).
_Avoid_: share, доступ по ссылке

## События и здоровье

**PetEvent (Событие питомца)**:
Запись о здоровье или уходе: плановая, выполненная или пропущенная (`planned | completed | missed`). Может иметь гостевого клиента (без аккаунта). Повторяющиеся события ставятся заново по расписанию; есть дублирование «сделать снова».
_Avoid_: запись, активность (размыто)

**EventType (Тип события)**:
Справочник видов событий (категории `surgery`, `parasite`, …) с `default_schema` (JSON) — сервер описывает поля формы, фронт рендерит динамически (server-driven UI).
_Avoid_: категория события (category — отдельное поле для группировки)

**Attribute / PetAttribute (Атрибут питомца)**:
Расширяемая характеристика питомца в схеме EAV (`attr_type: text | number | select | checkbox | date`) — вместо хардкода nullable-колонок под каждую породу/вид.
_Avoid_: поле, спецификация

## Ветеринары и клиники

**Vet (Ветеринар)**:
Пользователь с подтверждённой квалификацией (`is_verified` + `is_veterinarian`). Роль нельзя получить самообслуживанием через PATCH — только через admin-верификацию заявки.
_Avoid_: врач (в UI), doctor

**VetVerificationRequest (Заявка на верификацию)**:
Заявка врача с документами; approve → ветеринар верифицирован, reject → отклонена (сигналы в `users/signals.py`).
_Avoid_: заявка врача, документы

**VetClinic (Ветеринарная клиника)**:
Юридическая единица с кабинетом: пациенты, шаблоны осмотров, счета. Участники — `ClinicMember` (включая владельца).
_Avoid_: больница, ветцентр

**ExamTemplate (Шаблон осмотра)**:
Переиспользуемый набор услуг/процедур клиники, из которого быстро собирается событие или счёт.
_Avoid_: шаблон приёма

## Биллинг

**CatalogItem (Услуга каталога)**:
Единица прайса ветеринара (`code` уникален в пределах владельца), с ценой и складским остатком (`stock_quantity`).
_Avoid_: товар, позиция прайса

**Invoice (Счёт)**:
Финансовый документ клинике от клиента. Цены — снапшоты `name/price/tax_at_moment` на момент формирования, а не ссылки на каталог; итоги: `subtotal − discount + tax`. Оплата (`status=paid`) списывает `stock_quantity`.
_Avoid_: чек, платёж, Bill

**TemplateItem (Строка шаблона)**:
Составная единица шаблона осмотра (услуга + количество), из которой разворачиваются позиции событий/счетов клиники.
_Avoid_: позиция, пункт
